# Outreach materials

Ready-to-use drafts for organic discovery. All are optional and copy-paste.

| File                   | Target                                                    |
| ---------------------- | --------------------------------------------------------- |
| `discord-post.md`      | Stellar Discord `#dev-general` — single informational post |
| `dm-blend.md`          | Blend Capital team (Twitter / Discord)                    |
| `dm-phoenix.md`        | Phoenix Protocol team (Twitter / Discord)                 |
| `dm-paltalabs.md`      | PaltaLabs (DeFindex + Soroswap maintainers)               |

The long-form blog version lives at `../BLOG-FIRST-LOOK.md` and is intended
for dev.to / Medium / personal blog.

**Golden rules for sending these:**

1. Don't spam — one channel per target, max.
2. No ask in the first message. Let the link do the work.
3. If a team replies with a false positive, file it as an issue on the
   repo immediately and tune the rule — that is both good hygiene and
   demonstrates the project is maintained.
4. The tip-jar in the README is passive; never mention it in outreach.
